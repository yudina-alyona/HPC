**Описание проделанной работы**

В ходе работы были реализованы параллельные вычисления значения числа π методом Монте-Карло на центральном процессоре (CPU) и графическом процессоре (GPU) с использованием библиотеки Numba и ее подмодуля CUDA для работы с CUDA-ядрами. В соответствии с требованием лабораторной работы для генерации случайных чисел на GPU использовалась библиотека CURAND.

Эксперимент проводился на случайно сгенерированных точках в области (0, 0) - (1, 1) для различного количества точек N. Проводилось сравнение времени выполнения CPU и GPU, а также вычисленных значений числа π.

**CPU реализация**

Функция monte_carlo_cpu вычисляет число π методом Монте-Карло последовательно:
1. Для заданного количества точек N генерируются случайные координаты x и y;
2. Проверяется попадание точки в четверть единичного круга (условие x² + y² ≤ 1);
3. Если точка внутри круга, счетчик увеличивается;
4. По формуле π = 4× (количество попаданий) / N рассчитывается приближенное значение π.

**GPU реализация**

Функция monte_carlo_gpu_kernel представляет собой CUDA-ядро, где каждый поток обрабатывает одну точку:
1. Генерация случайных координат x и y выполняется непосредственно на GPU с использованием CURAND;
2. Каждый поток параллельно проверяет условие попадания точки в круг;
3. Параметры CUDA (threads_per_block = 256 и blocks_per_grid) настраиваются так, чтобы покрыть всё количество точек N;
4. После завершения работы ядра выполняется суммирование результатов и вычисление π.

Из полученных результатов можно сделать следующие выводы:
1. Время выполнения на CPU растет линейно с увеличением количества точек N, что соответствует теоретической сложности алгоритма O(N).
2. Время выполнения на GPU остается стабильно низким (0.0002-0.0004 сек) для всех N ≥ 2000. Это объясняется тем, что сотни потоков одновременно обрабатывают различные точки. При N = 1000 время GPU (0.00043 сек) уже меньше времени CPU (0.00145 сек), что демонстрирует эффективность GPU даже на небольших объемах данных.

С увеличением количества точек N ускорение значительно растет, что подтверждает эффективность параллельных вычислений на GPU для больших объемов данных. При N = 10000 GPU обрабатывает данные примерно в 55 раз быстрее CPU.

С увеличением N точность вычислений возрастает, что соответствует теории метода Монте-Карло (ошибка уменьшается пропорционально). Значения π на CPU и GPU близки друг к другу, что подтверждает корректность обеих реализаций.

Полученные результаты демонстрируют эффективность применения GPU для задач, где требуется обработка больших объемов случайных данных.
