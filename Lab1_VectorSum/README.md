# Описание проделанной работы

Лабораторная работа выполнена на языке Python в среде Google Colab с использованием библиотек NumPy, Numba и CUDA.

**Версия для CPU**

Функция vector_sum_cpu реализует последовательное суммирование элементов вектора с помощью обычного цикла. Каждый элемент по очереди прибавляется к результирующей переменной.

**Версия для GPU**

Функция vector_sum_gpu использует CUDA для параллельного суммирования. В ядре vector_sum_gpu_kernel каждый поток обрабатывает один элемент вектора. С помощью cuda.grid(1) каждому потоку назначается уникальный индекс, что позволяет распределить элементы вектора между всеми потоками. Затем внутри каждого блока выполняется алгоритм попарное сложение, после чего результаты всех блоков суммируются.

**Параллелизация**

Было распараллелено суммирование элементов вектора. В последовательной версии на CPU каждый элемент складывается по очереди, что для вектора из миллиона элементов требует миллиона операций. На GPU все эти операции выполняются одновременно с помощью потоков.
