# Описание проделанной работы

**Реализация алгоритмов**

Лабораторная работа реализована на языке Python в среде Google Colab. Были разработаны две версии алгоритма перемножения квадратных матриц: для центрального процессора и для графического ускорителя с поддержкой CUDA.

**Версия для CPU**

Алгоритм на процессоре построен по схеме трёх вложенных циклов. Внешние два цикла перебирают индексы строк и столбцов результирующей матрицы, а внутренний цикл вычисляет скалярное произведение соответствующей строки первой матрицы и столбца второй. Сложность такого подхода - кубическая, что делает его медленным при увеличении размерности входных данных.

**Версия для GPU**

Для реализации на видеокарте используется библиотека Numba и её возможности по компиляции кода в CUDA-ядра. Основная идея заключается в том, что каждый элемент результирующей матрицы вычисляется отдельным потоком на GPU. 

**Параллелизация**

В данной реализации распараллелено вычисление каждого отдельного элемента результирующей матрицы. Каждый элемент результата не зависит от остальных и может быть вычислен независимо. Такая независимость позволяет эффективно выполнять множество операций одновременно. Применение GPU становится  оправданным при работе с матрицами большого размера, где последовательный алгоритм на CPU становится непрактичным. На CPU все элементы вычисляются последовательно, а на GPU каждый из элементов вычисляется отдельным потоком. Таким образом, потоки работают одновременно, каждый выполняя свою независимую задачу.

В функции matmul_gpu_implementation задаётся размер блоков threads_per_block = (16, 16), то есть каждый блок содержит 256 потоков. Размер сетки блоков вычисляется как ceil(n / 16), чтобы покрыть всю результирующую матрицу. В CUDA-ядре cuda_kernel_matrix_multiply каждый поток получает свои глобальные индексы через i, j = cuda.grid(2). После проверки, что индексы не выходят за границы матрицы, поток вычисляет скалярное произведение строки i матрицы A и столбца j матрицы B в цикле по k, записывая результат в C[i, j].Таким образом, каждый поток обрабатывает один элемент результирующей матрицы, и все потоки работают параллельно и независимо.

# Результаты экспериментов

Тестирование проводилось для шести различных размеров матриц: от 100×100 до 2000×2000. Для каждого размера фиксировалось время выполнения на CPU и на GPU, а также вычислялось ускорение - отношение времени CPU ко времени GPU. Корректность обеих реализаций проверялась сравнением с эталонным результатом из библиотеки NumPy.

Полученные данные приведены в таблице:

| Размер | Время CPU (с) | Время GPU (с) | Ускорение | Корректность CPU | Корректность GPU |
|--------|---------------|---------------|-----------|------------------|------------------|
| 100    | 0.3546        | 0.1346        | 2.63      | True             | True             |
| 200    | 2.9347        | 0.0006        | 4904.00   | True             | True             |
| 400    | 26.4676       | 0.0034        | 7828.84   | True             | True             |
| 800    | 206.9425      | 0.0297        | 6964.90   | True             | True             |
| 1600   | 1677.4829     | 0.2008        | 8355.77   | True             | True             |
| 2000   | 3399.3910     | 0.3259        | 10430.04  | True             | True             |

*Время выполнения.* На CPU время выполнения растёт очень быстро: с 0.35 секунды для матрицы 100×100 до почти 3400 секунд (около часа) для матрицы 2000×2000. На видеокарте время выполнения растёт гораздо медленнее. Даже на самой большой матрице GPU справляется менее чем за полсекунды.

*Ускорение.* Для маленькой матрицы 100×100 ускорение составляет всего 2.63. Однако уже для матрицы 200×200 ускорение вырастает до почти 5000. В дальнейшем оно продолжает расти, достигая максимума 10430.04 на самом большом размере.

*Корректность.* Все результаты на CPU и GPU совпадают с эталоном, что подтверждает правильность реализации CUDA-ядра.

Результаты лабораторной работы демонстрируют, что параллельная реализация умножения матриц на GPU существенно превосходит последовательную реализацию на CPU. Для матрицы размером 2000×2000 ускорение составило более 10000 раз, а время выполнения сократилось с почти часа до менее чем одной секунды. Таким образом, использование GPU является эффективным решением для задач умножения матриц большой размерности.
